How to Use This Lab

General Rules

  • Select a measurement from the sidebar first — the correct tool loads automatically, and the instruction line above the display box tells you exactly what to measure for that mode.
  • Each measurement page just shows a live reading as you move the tool — there's no correctness check here. Read the value and note it down; you'll need it later.
  • The bone is locked in place during most measurements so it can't shift mid-reading. Double-click it to unlock/re-lock if a mode allows repositioning.
  • Take measurements in the order the sidebar lists them — the final Indices step needs the values you recorded from every earlier step.
  • Green/red feedback only appears on the Indices page, once you enter your recorded values into the formula boxes there.

Osteometric Board Length measurements

  1. Lay the bone flat against the board with the end you're measuring from touching the fixed wall.
  2. Drag the movable wall until it just touches the far end point of the bone for that measurement (no gap, no overlap).
  3. Read the value from the scale or display box and note it down.

Sliding Caliper Width / diameter measurements

  1. Drag the caliper body so the fixed jaw touches one side of the point you're measuring.
  2. Drag the movable slider until the moving jaw just touches the opposite side, along the axis named in the instruction line (e.g. transverse or vertical).
  3. Read the value and note it down.
The jaws should just contact the bone surface — don't compress it, and don't leave a gap.

Tape Curved / circumference measurements

  1. The tape stays fixed in place — drag the bone so the point you're measuring lines up with the tape, not the other way round.
  2. Position the bone so the tape sits exactly along the curve or distance named in the instruction line.
  3. Read the value and note it down.

Goniometer Angle measurements

  1. Drag the goniometer so its center pivot lines up with the joint or point named in the instruction line.
  2. Align the fixed arm along the first reference axis (usually the shaft).
  3. Drag the movable arm along the second reference axis until it matches the angle you're measuring.
  4. Read the angle in degrees and note it down.

Indices / Calculations Only page with feedback

  1. Open the Indices page once you've recorded all the raw measurements it needs.
  2. Enter your recorded values into each formula box — the result calculates as you type.
  3. Each answer box turns green automatically if correct, red if not. Adjust your input values until every box is green.
